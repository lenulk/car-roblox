# Garage Tycoon (เกมอู่ซ่อมรถ)

เกมแนว Tycoon ที่เล่นสบาย ๆ เล่นได้สูงสุด 4 คนต่อเซิร์ฟเวอร์ ผู้เล่นแต่ละคนมีอู่ซ่อมรถของตัวเองรอบ ๆ วงแหวนถนนกลาง
ลูกค้าจะขับรถมาให้คุณซ่อม คุณซ่อมรถเพื่อหาเงิน แล้วเอาเงินไปปลดล็อกอุปกรณ์และจ้างพนักงานเพิ่ม

## สถานะ: เฟส 1

**ใช้งานได้แล้ว:**

- วงแหวนถนนกลาง และอู่ 4 แห่ง (ผู้เล่นแต่ละคนได้อู่ 1 แห่ง และมีชื่อของตัวเองที่ป้ายประตู)
- ลูกค้ามี 3 ปัญหา: ยางแบน, เปลี่ยนน้ำมันเครื่อง, แบตเตอรี่หมด
- ซ่อมรถด้วยการกดค้างที่รถ (บนมือถือให้แตะ)
- ตู้เซฟ และแท่นเก็บเงิน (Collect pad): เงินจากการซ่อมจะเข้าตู้เซฟก่อน แล้วเดินไปที่แท่นเรืองแสงหน้าตู้เพื่อเก็บเงิน
- เคาน์เตอร์เก็บเงิน (Cashier)
- ปลดล็อกทีละขั้นตามลำดับ: ช่องซ่อมยาง (ฟรี) → เคาน์เตอร์แคชเชียร์ $250 → ช่องเปลี่ยนน้ำมันเครื่อง $800 → ชั้นวางแบตเตอรี่ $1,500 → ลานจอดรถที่ใหญ่ขึ้น $4,000
- บอร์ดจ้างงาน: พนักงานคนแรกฟรี (เลือกช่างซ่อมหรือแคชเชียร์)
- ลูกศรนำทาง (Guide arrow) บอกว่าควรไปทางไหนต่อ
- บทแนะนำ 3 ขั้นตอน (Tutorial) สำหรับผู้เล่นใหม่
- รองรับภาษาไทยและภาษาอังกฤษ
- บันทึกข้อมูลด้วย DataStore
- รองรับการเล่นบนโทรศัพท์มือถือ

**ยังไม่มี (เฟสถัดไป):**

- อัปเกรดอุปกรณ์ระดับ 1 ถึง 5
- ชั้นวางของและตำแหน่งพนักงานเพิ่มเติม
- ห้องพ่นสี, เครื่องยนต์, และห้องตรวจวินิจฉัย
- ลูกค้า VIP
- เพลงประกอบ
- รางวัลรายวัน
- ห้องปรับแต่งรถส่วนตัว

## ติดตั้งครั้งแรก (Windows)

### 1. ติดตั้ง Roblox Studio

ดาวน์โหลดและติดตั้ง Roblox Studio จากเว็บไซต์ของ Roblox แล้วล็อกอินด้วยบัญชี Roblox ของคุณ

### 2. ติดตั้ง Rojo 7.4

Rojo คือเครื่องมือที่ส่งโค้ดจากโฟลเดอร์ในคอมพิวเตอร์เข้าไปใน Studio
(จะใช้ตัวจัดการเครื่องมืออย่าง Aftman หรือ Rokit ก็ได้ แต่ไม่จำเป็น วิธีด้านล่างง่ายที่สุด)

1. เปิดหน้า Releases ของ Rojo: https://github.com/rojo-rbx/rojo/releases
2. หาเวอร์ชัน 7.4.x แล้วดาวน์โหลดไฟล์ที่ลงท้ายด้วย `windows.zip`
3. แตกไฟล์ซิป แล้วย้าย `rojo.exe` ไปไว้ในโฟลเดอร์ที่จำง่าย เช่น `C:\rojo`
4. เพิ่มโฟลเดอร์นั้นเข้า PATH: กดปุ่ม Windows พิมพ์ `environment variables` → "Edit the system environment variables" → "Environment Variables" → เลือก `Path` ใน User variables → "Edit" → "New" แล้วใส่ `C:\rojo` → กด OK ทุกหน้าต่าง จากนั้นปิดและเปิด Terminal ใหม่
5. ตรวจสอบ: พิมพ์ `rojo --version` ควรเห็นเลขเวอร์ชันขึ้นต้นด้วย 7.4

ติดตั้งปลั๊กอินใน Studio: ไปที่แท็บ **Plugins** → **Creator Store** → ค้นหา `Rojo` (ผู้สร้างคือ Rojo) → **Install**

### 3. ดาวน์โหลดโค้ดเกม

ถ้ายังไม่มีคำสั่ง `git` ให้ติดตั้ง Git for Windows ก่อน แล้วรันคำสั่งนี้ใน Terminal:

```
git clone https://github.com/lenulk/car-roblox.git
cd car-roblox
```

## เปิดเกมใน Studio

มีสองวิธี แนะนำให้ใช้วิธี A

### วิธี A: ซิงค์สด (แนะนำ)

1. เปิด Terminal ในโฟลเดอร์ `car-roblox` (คลิกขวาที่โฟลเดอร์ แล้วเลือก "Open in Terminal" หรือ "Open PowerShell window here")
2. รันคำสั่ง:
   ```
   rojo serve
   ```
   ปล่อย Terminal นี้ทำงานไว้ตลอดตอนพัฒนา
3. เปิด Roblox Studio แล้วเลือก **File → New → Baseplate**
4. ในหน้าต่าง Explorer ลบ `Baseplate` และ `SpawnLocation` ที่มาพร้อมกับเทมเพลตออก (เกมจะสร้างพื้นและจุดเกิดเองทั้งหมด)
5. ไปที่แท็บ **Plugins** กดปุ่ม **Rojo** แล้วกด **Connect**
6. กด **Play** (F5) เพื่อเริ่มเล่น

### วิธี B: สร้างเป็นไฟล์

รันคำสั่งนี้ในโฟลเดอร์ `car-roblox`:

```
rojo build -o GarageTycoon.rbxlx
```

แล้วเปิดไฟล์ `GarageTycoon.rbxlx` ด้วย Roblox Studio (File → Open หรือดับเบิลคลิกไฟล์)

## ตั้งค่าที่ต้องทำใน Studio

- **Security:** ไปที่ **Game Settings → Security** แล้วเปิด **Enable Studio Access to API Services**
  ถ้าไม่เปิด เกมยังเล่นได้ แต่ข้อมูลจะไม่ถูกบันทึก
- **Publish ก่อน:** ถ้า DataStore แจ้งเตือนให้ไปที่ **File → Publish to Roblox** ก่อน แล้วลองเล่นใหม่
- **Max Players = 4:** ไปที่ Game Settings (หรือหน้า Places บน Creator Dashboard) แล้วตั้ง Max Players เป็น `4`
  เพราะอู่มี 4 แห่ง จึงรองรับผู้เล่น 4 คนต่อเซิร์ฟเวอร์

- [ ] เดินไปที่รถ กดค้างปุ่ม **E** (บนมือถือให้แตะ) เพื่อซ่อม

- [ ] เปิดบอร์ดจ้างงาน แล้วจ้างพนักงานคนแรก (ฟรี)

### เล่นหลายคน

ในแท็บ **Test** เลือก **Clients and Servers** แล้วตั้งค่าเป็น **Local Server** จำนวน **4 players**
ผู้เล่นแต่ละคนจะได้อู่คนละแห่ง และป้ายประตูจะขึ้นชื่อของแต่ละคน

## เปลี่ยนโมเดลรถให้สวยขึ้น

คุณสามารถใส่โมเดลรถของตัวเองแทนรถพื้นฐานได้:

1. ใส่ Model ชื่อ `Car_Sedan` หรือ `Car_Pickup` ไว้ใน `ReplicatedStorage > Models` (เช่น คัดลอกมาจาก Toolbox)
2. รถลูกค้าที่เป็นประเภทนั้นจะใช้โมเดลของคุณโดยอัตโนมัติ

ข้อกำหนดของโมเดล:

- ชิ้นส่วนที่เป็นสีหลักของรถต้องชื่อ `Body`
- PrimaryPart (หรือ Part ชื่อ `Root`) ต้องอยู่ตรงกลางด้านล่างของรถ ระดับเดียวกับพื้น
- หน้ารถต้องหันไปทางแกน **-Z** (ตรงกับ LookVector ของโมเดล)

## โครงสร้างไฟล์

```
car-roblox/
├─ default.project.json     การตั้งค่า Rojo (แมปโฟลเดอร์ไปเป็นตำแหน่งใน Roblox)
├─ docs/
│  └─ CONTRACT.md           กฎที่โค้ดทุกไฟล์ต้องทำตาม
└─ src/
   ├─ shared/               → ReplicatedStorage.Shared
   │  ├─ Layout.luau        ตำแหน่งทั้งหมดของถนน อู่ และรถ
   │  ├─ Remotes.luau       ตัวสื่อสารระหว่างเซิร์ฟเวอร์กับผู้เล่น
   │  ├─ Format.luau / CarBuilder.luau
   │  └─ Config/            ราคา ปัญหา พนักงาน รถ และข้อความ (ไทย/อังกฤษ)
   ├─ server/               → ServerScriptService.Server
   │  ├─ Main.server.luau
   │  └─ Services/          ระบบฝั่งเซิร์ฟเวอร์ (เงิน ข้อมูลผู้เล่น ลูกค้า การซ่อม ฯลฯ)
   └─ client/               → StarterPlayer.StarterPlayerScripts.Client
      ├─ Main.client.luau / ClientState.luau / Theme.luau
      └─ Controllers/       ระบบ UI และเอฟเฟกต์ฝั่งผู้เล่น
```

`docs/CONTRACT.md` คือกฎที่ทุกไฟล์ในโปรเจกต์ต้องทำตาม ถ้าจะแก้โค้ด ให้อ่านไฟล์นี้ก่อน

## ปรับเกมง่าย ๆ

แก้ตัวเลขและข้อความได้โดยไม่ต้องเขียนโค้ดใหม่:

- `src/shared/Config/Game.luau`: ค่าหลักของเกม เช่น `STARTING_MONEY` (เงินเริ่มต้น) และ `SPAWN_INTERVAL_BASE` (เวลาระหว่างลูกค้าแต่ละคน, หน่วยเป็นวินาที)
- `src/shared/Config/Unlocks.luau`: ราคาของการปลดล็อกแต่ละอย่าง
- `src/shared/Config/Problems.luau`: ค่าจ้าง (pay) และเวลาซ่อม (time) ของแต่ละปัญหา
- `src/shared/Config/Strings.luau`: ข้อความทั้งหมดที่แสดงในเกม (ไทยและอังกฤษ)

**หมายเหตุ:** ถ้าเปลี่ยนค่า `DATASTORE_NAME` ข้อมูลเซฟของผู้เล่นทั้งหมดจะถูกรีเซ็ต
ใช้เฉพาะตอนที่ต้องการเริ่มข้อมูลใหม่จริง ๆ

3. เฟสถัดไปคือ **Phase 2** ซึ่งจะเพิ่มระบบที่อยู่ในรายการ "ยังไม่มี" ด้านบน
