# งานสำหรับ Kiro: ฉากเปิดเกม (Prologue) — แข่งในสนามใหญ่ แล้วรถพังโค้งสุดท้าย

## บริบท
- โปรเจกต์ Roblox (Rojo + Luau `--!strict`) เกม garage tycoon ส่วนเล่นหลักเสร็จแล้ว
- งานรอบนี้: **ผู้เล่นใหม่ที่เข้าเกมครั้งแรก** จะได้เล่นฉากเปิดก่อน
  1. ภาพเปิดโชว์สนามแข่งใหญ่ อัฒจันทร์เต็มไปด้วยคนดู
  2. ผู้เล่นออกสตาร์ทเป็นคันสุดท้าย (อันดับ 7/7) แล้ว **ขับเอง 1 รอบ** ไต่อันดับขึ้นไปเรื่อย ๆ
  3. ถึงโค้งสุดท้ายตอนกำลังจะชนะ **เครื่องระเบิด** รถมีควันและไฟ ไหลไปจอดเอง คู่แข่งแซงผ่านไป คนดูร้องตกใจ
  4. จอดำ ขึ้นข้อความเล่าเรื่อง: รถในฝันพัง ต้องเปิดอู่ซ่อมเอง
  5. ผู้เล่นไปโผล่ที่อู่ (แปลงของตัวเอง) แล้ว Tutorial เดิมเริ่มต่อตามปกติ
- ฉากนี้เล่น **ครั้งเดียว** ต่อบัญชี มีปุ่ม "ข้าม" ตลอดเวลา
- อ่านก่อนเริ่ม: `docs/CONTRACT.md`, `docs/KIRO_SHOWCAR_TRACK_PROMPT.md` (กติกาและสไตล์เดิม)
- ไฟล์หลักที่เกี่ยวข้อง:
  - `src/server/Services/PlayerData.luau` (`Data` type, `defaultData`, `reconcile`, `buildSnapshot`, `onSetSetting` ~บรรทัด 245)
  - `src/client/Main.client.luau` (โหลดทุก ModuleScript ใน `Controllers/` อัตโนมัติ ต้องมี `start()`)
  - `src/client/ClientState.luau` (`onChanged(fn)`, `lang()`)
  - `src/client/Controllers/Localizer.luau` (`t`, `bind`), `src/client/Theme.luau` (`newGui`, `panel`, `label`, `colors`)
  - `src/client/Controllers/Music.luau` (`setWanted(bool)`)
  - `src/client/Controllers/Tutorial.luau`, `src/client/Controllers/Guide.luau`
  - `src/shared/CarBuilder.luau` (`build(carTypeId, { color })` — อยู่ใน shared, client เรียกได้)
  - `src/shared/SoundFx.luau` (`play`, `attach`, `release`) + `src/shared/Config/Sounds.luau`
  - `src/shared/Config/PersonalCars.luau` (stats ของรถ ใช้อ้างอิงความเร็ว)
  - Strings: `src/shared/Config/StringsUI.luau`

## กติกาที่ต้องทำตาม
1. **ใช้เฉพาะ Enum/property/API ที่มีจริงใน Roblox** ไม่แน่ใจให้ตรวจเอกสารก่อน (เคยพังเพราะ `Material.Rust`)
2. `--!strict` ต้องไม่มี type error สไตล์เหมือนไฟล์เดิม (tab, คอมเมนต์ภาษาอังกฤษสั้น ๆ)
3. **ห้ามเพิ่ม RemoteEvent/RemoteFunction ใหม่** ใช้ `SetSetting` เดิม (ดูข้อ A.2)
4. ทุก Strings key ที่เพิ่มต้องมีทั้ง `th` และ `en` (ชุด key สองภาษาต้องเท่ากัน)
5. ห้าม `math.clamp(x, min, max)` ที่ min อาจมากกว่า max
6. ห้ามแตะ `GarageTycoon.rbxlx`, ห้าม `git commit`, ห้ามแก้ไฟล์ที่ไม่เกี่ยว, ห้ามเปลี่ยน `STARTING_MONEY`
7. ห้าม loop `while true` ใช้ `RunService.RenderStepped`/`Heartbeat` connection เดียวสำหรับทั้งฉาก แล้ว disconnect ตอนจบ
8. **ทุกอย่างของฉากต้องถูกลบทิ้งหมดเมื่อจบหรือข้าม** (สนาม, รถ, คนดู, GUI, เสียง, connection) ไม่ทิ้งอะไรค้างใน workspace
9. **ห้ามใช้ `Instance.new("Explosion")`** (มันฆ่าตัวละครและทำลาย joint) ทำระเบิดด้วย ParticleEmitter/แสงแทน
10. `NpcBuilder` อยู่ใน `ServerScriptService` **client require ไม่ได้** ห้ามย้ายมัน คนดูให้สร้างเองแบบง่าย (ข้อ B.4)

## หลักการออกแบบ (สำคัญ อ่านก่อนเขียนโค้ด)
- **ทั้งฉากสร้างและรันฝั่ง client ของผู้เล่นคนนั้นเท่านั้น** (สนาม, รถเรา, รถคู่แข่ง, คนดู) server ไม่รู้เรื่องสนามเลย
  เหตุผล: ผู้เล่นหลายคนเข้าเกมพร้อมกันจะได้ไม่เห็นรถกันและกัน และไม่มีปัญหา network ownership
- **รถในฉากนี้ไม่ใช้ฟิสิกส์ และไม่ใช้ `VehicleBuilder`/`VehicleController`** ให้ใช้ระบบ "track-space":
  ตำแหน่งรถแต่ละคัน = `s` (ระยะทางตามเส้นกลางสนาม) + `d` (ระยะเบี่ยงซ้าย/ขวาจากเส้นกลาง)
  แล้ววางรถด้วย `PivotTo` ทุกเฟรม รถ Anchored ทั้งคัน `CanCollide = false`
  ข้อดี: ไม่หลุดสนาม ไม่พลิก คุมจังหวะเรื่องได้แน่นอน และทำงานเหมือนกันทั้งคอมและมือถือ
- ตัวละครผู้เล่นยังอยู่ที่แปลงของตัวเองตลอด (ไม่ย้าย) แค่ anchor `HumanoidRootPart` ฝั่ง client ไว้และย้ายกล้องไปที่สนาม

## ส่วน A — ข้อมูลผู้เล่น (server, เล็ก)

### A.1 ฟิลด์ใหม่ใน `PlayerData`
- เพิ่ม `prologueDone: boolean` ใน `Data` type และ `defaultData` (= `false`)
- **ผู้เล่นเก่าต้องไม่เห็นฉากนี้:** หลัง `reconcile` ตอนโหลดเซฟ ถ้าเซฟเดิมยังไม่มีฟิลด์นี้ และผู้เล่นเคยเล่นแล้ว
  (`carsRepaired > 0` หรือ `totalEarned > 0` หรือ `tutorialStep > 1`) ให้ตั้ง `prologueDone = true`
- เพิ่ม `prologueDone` ใน snapshot (ใน `buildSnapshot` หรือผ่าน `addSnapshotField`)

### A.2 บันทึกว่าดูจบแล้ว
- ใน `onSetSetting` เพิ่มกรณี `key == "prologueDone" and value == true` → `data.prologueDone = true`
  (เปลี่ยนได้แค่ false → true เท่านั้น ห้ามรับค่าอื่น)
- client เรียก `Remotes.get("SetSetting"):FireServer("prologueDone", true)` ตอนฉากจบหรือกดข้าม

## ส่วน B — ฉากเปิด (client)

### B.0 โครงไฟล์
```
src/shared/Config/Prologue.luau          -- ค่าปรับแต่งทั้งหมด (ตำแหน่ง, ความเร็ว, จำนวนคนดู, เวลา)
src/client/Controllers/Prologue.luau      -- controller หลัก มี start() คุมลำดับฉาก
src/client/Prologue/Track.luau            -- เส้นทางสนาม + ฟังก์ชันแปลง (s, d) -> CFrame
src/client/Prologue/ArenaBuilder.luau     -- สร้างพื้นถนน รั้ว อัฒจันทร์ ป้าย ไฟ ซุ้มสตาร์ท
src/client/Prologue/Crowd.luau            -- คนดู + แอนิเมชันเชียร์/ตกใจ
src/client/Prologue/RaceCars.luau         -- รถเรา + รถคู่แข่ง (track-space)
src/client/Prologue/PrologueUI.luau       -- จอดำ, ข้อความ, นับถอยหลัง, HUD อันดับ, ปุ่มข้าม
```
**ห้ามวางโมดูลย่อยไว้ใน `Controllers/`** (Main จะ require ทุกไฟล์ในนั้นแล้ว warn ว่าไม่มี `start()`) `src/client/Prologue/` จะ map เป็น `Client.Prologue` อยู่แล้วผ่าน `default.project.json`

`Config/Prologue.luau` ต้องมีอย่างน้อย:
- `ARENA_ORIGIN = Vector3.new(0, 0, 5000)` (ไกลจากแผนที่หลัก ตรวจว่าไม่ทับอะไรใน workspace)
- `FORCE_IN_STUDIO = false` — ถ้า true ให้เล่นฉากทุกครั้งใน Studio แม้ `prologueDone` จะเป็น true (ไว้ทดสอบ)
- ความเร็ว, จำนวนคู่แข่ง, จำนวนคนดู, ระยะเวลาแต่ละช่วง (ทุกตัวเลขที่ปรับได้ให้อยู่ที่นี่ ไม่ฝังในโค้ด)

### B.1 เงื่อนไขเริ่มและการเตรียมตัว
- `Prologue.start()` รอ snapshot แรกจาก `ClientState.onChanged` ถ้า `snapshot.prologueDone == true` (และไม่ได้ force) → จบ ไม่ทำอะไร
- ต้องเริ่มให้เร็วที่สุด: **ใส่จอดำทันทีที่ `start()`** (ก่อนรอ snapshot) แล้วค่อยเอาออกถ้าไม่ต้องเล่นฉาก ผู้เล่นใหม่จะได้ไม่เห็นอู่แวบหนึ่งก่อนเข้าฉาก
- ตอนเริ่มฉาก:
  - ตั้ง attribute `LocalPlayer:SetAttribute("InPrologue", true)`
  - ซ่อน ScreenGui อื่นทั้งหมดใน `PlayerGui` (จำค่า `Enabled` เดิมไว้แล้วคืนตอนจบ) รวมถึง GUI ที่ถูกสร้างทีหลังระหว่างฉาก (ฟัง `ChildAdded`) — popup รายวัน/เงินออฟไลน์จะได้โผล่หลังฉากจบแทน
  - `Guide` และ `Tutorial` ต้องเช็ก attribute `InPrologue` แล้วซ่อนลูกศร/การ์ด (แก้สองไฟล์นี้ให้น้อยที่สุด)
  - `Music.setWanted(false)` แล้วคืนค่าตอนจบ
  - anchor `HumanoidRootPart` ฝั่ง client (ถ้า character respawn ระหว่างฉาก ต้อง anchor ใหม่) **ไม่ต้อง** disable ControlModule เพราะเราอ่าน `GetMoveVector()` จากมัน
  - `Camera.CameraType = Scriptable` ระหว่างฉาก คืนเป็น `Custom` และ `CameraSubject = Humanoid` ตอนจบ

### B.2 สนาม (`Track.luau` + `ArenaBuilder.luau`)
- สนามวงปิด 1 รอบ ยาวประมาณ **3,000–3,600 studs** กว้าง **44 studs** พื้นราบ (Y คงที่) มี:
  ทางตรงหลักยาว (มีอัฒจันทร์ใหญ่สองฝั่ง), โค้งความเร็วสูง 2 โค้ง, โค้งหักศอก 1 โค้ง, และ **โค้งสุดท้ายก่อนเข้าทางตรงหลัก** (เป็นจุดเกิดเหตุ ต้องมองเห็นจากอัฒจันทร์)
- `Track.luau` เก็บ path เป็นจุด ๆ (ห่างกัน ≤ 20 studs หลัง smooth) แล้วมีฟังก์ชัน:
  - `Track.cframeAt(s, d): CFrame` (หันตามทิศทางสนาม, วนรอบด้วย `s % length`)
  - `Track.length`, `Track.halfWidth`
  - คำนวณความโค้งต่อจุดไว้ล่วงหน้า (ใช้ให้รถคู่แข่งชะลอในโค้ง)
- `ArenaBuilder` สร้างทั้งหมดใน `Folder` เดียวชื่อ `PrologueArena` ใต้ `workspace` (ลบทั้ง folder ตอนจบ):
  - พื้นถนนสีเข้ม เส้นขอบขาว-แดงที่โค้ง (kerb), เส้นสตาร์ทลายตารางหมากรุก, กริดสตาร์ท 7 ช่อง
  - รั้วกั้นสองข้าง, ยางกันชนในโค้ง, หญ้ารอบ ๆ
  - อัฒจันทร์ขั้นบันได: ทางตรงหลักสองฝั่ง + โค้งสุดท้าย + ด้านนอกโค้งหักศอก
  - ซุ้มสตาร์ทคร่อมถนน มีไฟ 3 ดวง (แดง → เขียว), ป้ายโฆษณา/ธงสีต่าง ๆ, เสาไฟสนาม (PointLight/SpotLight ไม่กี่ดวงพอ)
- **งบชิ้นส่วน: ทั้งสนามรวมคนดูไม่เกิน ~4,000 Part** ใช้ Part ยาว ๆ แทนหลายชิ้นเล็ก, `CastShadow = false` กับของตกแต่ง, ทุกชิ้น Anchored
- สร้างแบบแบ่งเฟรม (`task.wait()` ทุก ๆ ~300 ชิ้น) ระหว่างจอดำ เพื่อไม่ให้เกมค้าง

### B.3 รถ (`RaceCars.luau`)
- **รถเรา:** `CarBuilder.build("Super", { color = ... })` สีโดดเด่น (เช่นแดง) มีเลขบนรถได้ถ้าทำง่าย
- **คู่แข่ง 6 คัน:** ประเภทและสีคละกัน (`Sports`, `Muscle`, `Super` ฯลฯ)
- ทุกคันทำให้ Anchored + `CanCollide = false` ทั้งคัน วางด้วย `PivotTo(Track.cframeAt(s, d) * ยกขึ้นให้ล้อแตะพื้น)`
- **การบังคับของผู้เล่น** (อ่านจาก `PlayerModule:GetControls():GetMoveVector()` ใช้ได้ทั้งคีย์บอร์ด, จอยมือถือ, gamepad):
  - **เร่งอัตโนมัติ** ถึงความเร็ว cruise (~75 studs/s), กดเดินหน้า = ความเร็วสูงสุด (~95), กดถอย = เบรก (ไม่ต้องมีถอยหลัง)
  - ซ้าย/ขวา = เปลี่ยน `d` (ยิ่งเร็วยิ่งเลี้ยวช้าลงเล็กน้อย) หมุนตัวรถเอียงตามทิศที่เลี้ยวนิดหน่อยให้ดูเป็นธรรมชาติ
  - ชนขอบสนาม: `d` ถูกจำกัดในสนาม และลดความเร็ว ~30% พร้อมประกายไฟ
  - ชนคู่แข่ง (ห่างตามสนาม < ความยาวรถ และห่างด้านข้าง < ความกว้างรถ): ดันแยกด้านข้าง คันที่อยู่หลังเสียความเร็วเล็กน้อย
  - ล้อหมุนตามความเร็ว (ถ้ามีชิ้นล้อแยกใน model ของ CarBuilder)
- **คู่แข่ง (AI แบบมีสคริปต์):**
  - ตั้งต้นอยู่หน้าผู้เล่นทั้งหมด (ผู้เล่นอยู่ช่องสุดท้ายของกริด)
  - วิ่งตามเลนของตัวเอง ชะลอในโค้งตามความโค้ง หลบผู้เล่น/กันเองด้านข้างแบบง่าย
  - **rubber-band:** ความเร็วคู่แข่งปรับตามระยะห่างจากผู้เล่น เพื่อให้ผู้เล่นทั่วไป (รวมถึงเด็กที่ขับไม่เก่ง) ไต่ขึ้นมาได้ถึงอันดับ 1–2 ก่อนโค้งสุดท้าย แต่คู่แข่งไม่ช้าจนดูหลอก
- **กล้องระหว่างแข่ง:** ตามหลังรถเรา (สูง ~8, ถอยหลัง ~22 studs) แบบ lerp นุ่ม ๆ FOV เพิ่มขึ้นเล็กน้อยตามความเร็ว

### B.4 คนดู (`Crowd.luau`)
- คนดู **~600–800 คน** บนอัฒจันทร์ แต่ละคน = 2–3 Part (ตัว + หัว + อาจมีแขนชูหนึ่งข้าง) สีเสื้อสุ่ม สีผิวสุ่มจากชุดสีที่เหมาะสม
- คนดูบางส่วนถือป้าย/ธงสีสด
- แอนิเมชัน (ฝั่ง client เท่านั้น ประหยัดเครื่อง):
  - ปกติ: เด้งขึ้นลงเบา ๆ เฟสสุ่ม อัปเดตเฉพาะคนที่อยู่ในระยะ ~300 studs จากกล้อง ใช้ `workspace:BulkMoveTo` ทีเดียวต่อเฟรม
  - **เชียร์** (ตอน GO, ตอนผู้เล่นแซง, ตอนขึ้นอันดับ 1): กระโดดสูงขึ้น 1–2 วินาที
  - **ตกใจ** (ตอนเครื่องระเบิด): หยุดเด้ง ทุกคนหันไปทางรถ/โน้มตัวไปข้างหน้า
- พลุ/กระดาษสีจาก ParticleEmitter ตอน GO

| 2 นับถอยหลัง | ~4 วิ | กล้องไปหลังรถเรา ไฟซุ้มติดทีละดวง 3-2-1 แล้วเขียว "GO!" ก่อน GO ขยับไม่ได้ |
| 3 แข่ง | ~40–60 วิ | ผู้เล่นขับ HUD แสดงอันดับ (P7/7), ความเร็ว, แถบความคืบหน้าในรอบ ข้อความผู้บรรยายเด้งขึ้นตามเหตุการณ์ (แซง, ขึ้นนำ ฯลฯ) |
| 4 เครื่องเริ่มมีปัญหา | ที่ ~85% ของรอบ | ควันเทาจากฝากระโปรงเริ่มออก ไฟเตือน "ENGINE!" กระพริบใน HUD เสียงเครื่องสะดุด ความเร็วตกนิดหน่อย |
| 5 ระเบิด | ที่ ~92% ของรอบ (กลางโค้งสุดท้าย) | แสงวาบ + ประกายไฟ + ควันดำ + เปลวไฟ (ParticleEmitter/PointLight) ตัดการบังคับ รถไหลชะลอจนหยุดใน ~3 วิ ไปทางขอบสนาม กล้องเปลี่ยนเป็นมุมภาพยนตร์หมุนรอบรถช้า ๆ คู่แข่งวิ่งแซงผ่านไป คนดูตกใจ ผู้บรรยาย "โอ้ไม่! เครื่องพัง!" |
| 6 เล่าเรื่อง | 3 การ์ด ~3 วิต่อการ์ด | fade เป็นจอดำ ขึ้นข้อความทีละการ์ด (แตะเพื่อไปต่อได้) |
| 7 ไปอู่ | ~2 วิ | ลบทุกอย่าง คืนกล้อง/GUI/เพลง/ตัวละคร ส่ง `SetSetting("prologueDone", true)` แล้ว fade in ที่อู่ ขึ้นข้อความเล็ก ๆ "ยินดีต้อนรับสู่อู่ของคุณ!" |

- **กันติด:** ถ้าผ่านช่วง 3 ไปแล้ว 120 วิ ยังไม่ถึง 85% ของรอบ (ผู้เล่นจอดเฉยหรือเล่นไม่เป็น) ให้เข้าช่วง 4–5 ทันทีที่ตำแหน่งปัจจุบัน
- เหตุการณ์ช่วง 4–5 ต้องเกิด **ไม่ว่าผู้เล่นจะอยู่อันดับไหน** (rubber-band ช่วยให้ส่วนใหญ่อยู่อันดับ 1–2 อยู่แล้ว)
- **ปุ่มข้าม** (มุมขวาบน ใหญ่พอสำหรับนิ้วบนมือถือ) กดได้ตั้งแต่ช่วง 1 ถึง 5 → ข้ามไปช่วง 6 แต่แสดงแค่การ์ดสุดท้าย แล้วไปช่วง 7
- ถ้าผู้เล่นออกจากเกมกลางฉาก จะไม่ถูกบันทึกว่าดูจบ → เข้ามาใหม่ได้ดูอีกครั้ง (ถูกต้องตามที่ต้องการ)

### B.6 เสียง
- เพิ่ม key ใน `Config/Sounds.luau` **โดยให้ `id = ""` (ปิดไว้)** ผู้ใช้จะอัปโหลดไฟล์เสียงเองทีหลัง:
  `crowdLoop` (looped), `crowdCheer`, `crowdGasp`, `countdownBeep`, `countdownGo`, `raceEngine` (looped, ปรับ `PlaybackSpeed` ตามความเร็ว), `engineSputter`, `engineBlow`
- เรียกผ่าน `SoundFx.play/attach` เท่านั้น ถ้า id ว่าง SoundFx จะไม่สร้างอะไร โค้ดต้องรองรับกรณีได้ `nil` กลับมา
- เสียงที่ไม่ผูกกับตำแหน่ง (นับถอยหลัง, เสียงคนดูรวม) ให้ parent ไว้กับ `SoundService` หรือกล้อง ส่วนเครื่องยนต์ parent ไว้กับรถ
- `release` ทุกเสียงตอนจบฉาก

### B.7 UI (`PrologueUI.luau`)
- ใช้ `Theme` และ `Localizer` เหมือนส่วนอื่น `DisplayOrder` สูงกว่า GUI อื่นทั้งหมด `IgnoreGuiInset = true`
- จอดำแบบ fade (`TweenService`)
- ตัวเลขนับถอยหลังกลางจอ ขนาดใหญ่
- HUD ระหว่างแข่ง: อันดับ `P3/7` ตัวใหญ่, ความเร็ว, แถบความคืบหน้า, ไฟเตือน ENGINE
- กล่องข้อความผู้บรรยายแบบ subtitle ด้านล่าง (อยู่ ~2.5 วิ ไม่ซ้อนกัน)
- การ์ดเล่าเรื่องกลางจอ ตัวใหญ่ อ่านง่ายบนมือถือ
- ทุกอย่างต้องใช้ได้บนจอมือถือแนวนอน (ทดสอบด้วย Device Emulator)

## นอกขอบเขตรอบนี้ (ห้ามทำ)
- ระบบ "ซ่อมรถในฝันให้กลับมาแข่ง" (จะเป็นงานรอบหน้า) — รอบนี้แค่เล่าเรื่องในการ์ด
- ปุ่ม "ดูฉากเปิดอีกครั้ง" ในเมนูตั้งค่า
- การอัปโหลดเสียง/โมเดลจาก Marketplace

## เกณฑ์ผ่าน
- ผู้เล่นใหม่ (เซฟว่าง หรือ `FORCE_IN_STUDIO = true`): เข้าเกม → จอดำ → เห็นสนาม คนดูเต็ม → นับถอยหลัง → ขับได้ → ไต่อันดับได้ → ควัน → ระเบิดในโค้งสุดท้าย → การ์ดเล่าเรื่อง → โผล่ที่อู่ Tutorial ขั้นที่ 1 แสดงตามปกติ
- ไม่เห็นอู่หรือ HUD ปกติแวบขึ้นมาก่อนเข้าฉาก
- กดข้ามได้ทุกช่วง → ไปจบที่อู่ถูกต้อง
- ออกแล้วเข้าใหม่หลังดูจบ → ไม่เล่นฉากอีก ผู้เล่นเก่าที่มีความคืบหน้าอยู่แล้ว → ไม่เห็นฉากเลย
- ผู้เล่น 2 คนเข้าพร้อมกัน (Studio Test → 2 Players) → ต่างคนต่างเล่นฉากของตัวเอง ไม่เห็นรถของอีกฝ่าย
- หลังจบ: `workspace` ไม่มี `PrologueArena` เหลืออยู่, กล้องตามตัวละคร, เดินได้, เพลงกลับมา, GUI เดิมกลับมาครบ
- ไม่ขับแล้วปล่อยทิ้ง → ฉากยังจบเองได้ภายในเวลาที่กำหนด
- บนมือถือ (Device Emulator): บังคับได้ด้วยจอย ปุ่มข้ามกดง่าย ตัวหนังสือไม่ล้นจอ
- FPS ไม่ตกจนกระตุกชัดเจนระหว่างแข่ง Output ไม่มี error/warning ใหม่
- หลังทดสอบ: **ตั้ง `FORCE_IN_STUDIO = false` คืน**
